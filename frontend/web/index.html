Under the hood

How the Prediction Works

1. Input your trip parameters
Destination, duration, travelers, accommodation tier, transport mode, season, meal plan.
2. Preprocessing pipeline
StandardScaler on numerics · OrdinalEncoder on ranked categories · OneHotEncoder on nominal categories.
3. Gradient Boosting model
400 sequential decision trees trained with learning_rate=0.05, max_depth=5, subsample=0.8.
4. Result with confidence bounds
Predicted INR amount ± 11.2% MAPE-based confidence interval returned in <100ms.
